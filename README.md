# BirthdayStudio 🎂

在本地制作一份可互动的生日网页。本仓库仅用于通用版下载，不包含开发源码。

1. 在 [Releases](../../releases) 的 **Assets** 下载 `BirthdayStudio.zip`，不要选择 GitHub 自动生成的 `Source code`。
2. 完整解压，打开 `BirthdayStudio/打开编辑器.html`。推荐 Chrome 或 Edge，无需安装 Node.js，也无需联网。
3. 添加照片和祝福，预览后导出礼物。含私人照片或祝福的礼物请只发给预期收件人。
